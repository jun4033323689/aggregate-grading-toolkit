# 混凝土骨料筛分数据的口径约定

> 本文说明「分计筛余 / 累计筛余 / 通过率 / 细度模数 / 级配区」之间的换算关系与常见错法。
> 附录表格摘自 JGJ 52-2006，**使用前请与现行有效版本核对**；本文不提供规范解释权。

---

## 1. 三组量，一次说清

一次筛分试验得到的是**每个筛上的存量**，其它两列都是它的派生量。

| 名称 | 符号 | 定义 | 单位 |
|---|---|---|---|
| 分计筛余 | `R[i]` | 留在第 i 级筛上的质量占试样总质量的百分数 | % |
| 累计筛余 | `CR[i]` | 第 i 级及**更粗**所有筛上存量的累计 | % |
| 通过率 | `P[i]` | 能通过第 i 级筛的质量百分数 | % |

换算：

```
CR[i] = Σ(j=0..i) R[j]          # i = 0 对应最大筛孔
P[i]  = 100 − CR[i]
Σ(i) R[i] ≈ 100                 # 含筛底，允许 98~102 的筛分损耗
```

**关键在 `i = 0` 是谁。** 混凝土筛分记录习惯把筛孔按**降序**排列（4.75 → 2.36 → 1.18 → 0.60 → 0.30 → 0.15），此时 `i = 0` 就是最大筛孔 4.75，累积方向是「从粗到细」。

若把表格按升序排列再照抄公式，累计筛余会从细端开始累加，得到一条**整体反向**的曲线。它看起来仍然平滑、仍然单调，不报警、不崩溃，只是全错 —— 这是本领域最危险的一类错误。

## 2. 细度模数

砂的细度模数定义为六个标准筛累计筛余之和的归一化：

```
μf = [(β2 + β3 + β4 + β5 + β6) − 5·β1] / (100 − β1)
```

- `β1 … β6`：4.75 / 2.36 / 1.18 / 0.60 / 0.30 / 0.15 mm 筛的累计筛余，%
- 分子里 `− 5·β1` 来自「五个筛各扣除一次 4.75mm 以上的存量」这一几何事实
- 分母 `100 − β1` 把「可参与级配的部分」重新归一化到 100

**为什么不能直接除以 100**：只有当 β1 = 0 时，`100 − β1 = 100`，两种写法才巧合相等。实际生产中机制砂、粗砂常带 3%~8% 的 4.75mm 存量，此时两种算法的差值可达 0.1 以上。

算例（β1 = 5%）：

```
累计筛余 β:  5, 20, 40, 60, 80, 95
正确：(20+40+60+80+95 − 5×5) / (100−5) = 270 / 95 = 2.84
错法：(20+40+60+80+95)      / 100      = 295 / 100 = 2.95
```

细度模数分级（GB/T 14684 口径）：

| μf | 分类 |
|---|---|
| < 1.5 | 特细砂 |
| 1.5 ~ 2.2 | 细砂 |
| 2.2 ~ 3.0 | 中砂 |
| 3.0 ~ 3.7 | 粗砂 |
| > 3.7 | 超粗砂 |

## 3. 砂颗粒级配区（JGJ 52-2006 表 4.2.2，累计筛余 %）

| 筛孔 (mm) | I 区 | II 区 | III 区 |
|---|---|---|---|
| 4.75 | 10 ~ 0 | 10 ~ 0 | 10 ~ 0 |
| 2.36 | 35 ~ 5 | 25 ~ 0 | 15 ~ 0 |
| 1.18 | 65 ~ 35 | 50 ~ 10 | 25 ~ 0 |
| 0.60 | 85 ~ 71 | 70 ~ 41 | 40 ~ 16 |
| 0.30 | 95 ~ 80 | 92 ~ 70 | 85 ~ 55 |
| 0.15 | 100 ~ 90 | 100 ~ 90 | 100 ~ 90 |

判定逻辑：**六个筛的累计筛余同时落在某一区的上下限内**，即判定属于该区。

注意两点：

1. **同一个砂可能同时满足多个区**（区间有重叠），此时如实报告命中的全部区，而不是随便挑一个。
2. **都不满足就是不满足**，不存在「最接近哪个区」。最常见的不满足原因是**断级配**：中间某一级缺失，导致某一筛的累计筛余跳变。此时曲线肉眼可见地「折了一下」，但单点判定容易漏。

## 4. 为什么本工具不内置碎石级配表

碎石/卵石的连续级配表按**公称粒径**分档（5–20、5–25、16–31.5、5–31.5 等），每档一张子表，且不同版本规范、不同工程要求会调整。

内置一张可能过时或抄错的表，比不内置更糟 —— 用户会以为「工具算过了就是对的」。

因此本工具对碎石只做**通用的数据体检**（换算方向、合计、单调性、细粉口径），级配判定请自行提供上下限。如果你需要在工具里加石表，正确做法是：

1. 把现行规范的表值抄进 `SAND_GRADING_ZONES` 同构的对象里；
2. 在 `analyze()` 里按 `kind === 'stone'` 分支套用；
3. 在 README 写明版本与出处。

## 5. 细粉（石粉）含量

混凝土行业说的「石粉含量」通常指 **<0.075mm** 的颗粒含量，对机制砂是必检项。

两种口径不能混：

| 筛分是否做到 0.075mm | 正确算法 | 说明 |
|---|---|---|
| 是 | `100 − Σ(全部分计筛余)` | Σ 包含 0.075 筛上与筛底 |
| 否（只到 0.15mm） | 无法得到 <0.075mm 含量 | 「0.15mm 通过率」= <0.15mm 全部通过量，比石粉含量大 |

把后者当石粉含量报，会系统性高估。例如只筛到 0.15mm 时通过率 7%，真实石粉可能是 0%，也可能是 6% —— 取决于 0.075 筛上的存量，而这恰恰是没测的。

## 6. Fuller 曲线只是参照，不是标准

Fuller 曲线（n ≈ 0.5）：

```
P(d) = 100 · (d / D)^n
```

它是 20 世纪初提出的**连续级配理想解**，用来描述「什么样的粒径分布最密实」。它的价值在于给出一条参照线，让你一眼看出实测曲线是偏粗还是偏细、哪一段有平台。

它**不是**判定依据：

- 实际骨料受母岩、破碎工艺、级配设备限制，很难完全贴合；
- 现行规范给的是**区间**（级配区/级配范围），不是单条曲线；
- 用 Fuller 偏差去「优化」配比，属于另一个层面的工作（堆积模型与寻优），不在数据校验工具的范围里。

后续理论（如 Dinger-Funk 引入有限最小粒径 d_min）会修正 Fuller 在细端的偏差，同样属于配比设计范畴。

## 7. 一份可直接照做的自查清单

拿到一张筛分记录，按顺序问六件事：

1. 筛孔是不是**降序**排的？（4.75 在最上面）
2. 分计筛余合计是不是在 **98~102%**？不在 → 先找漏项，别急着算。
3. 累计筛余第 4.75mm 那一格，是不是等于它自己的分计筛余？（必须是）
4. 通过率是不是**逐级下降**？出现上升 → 数据或公式反了。
5. 细度模数用的是 `(Σβ − 5β1)/(100 − β1)` 还是 `Σβ/100`？β1 ≠ 0 时两者不等。
6. 石粉含量是按 0.075 筛算的，还是拿 0.15 通过率顶的？

六条全过，这组数据才算「能拿去用」。
